Quoted data matters: Jev selects the values in your step, it never invents them, so "alice@example.com" resolves and an unquoted description of an email does not. Page-like control names matter too — "the Log in button" or a quoted "Log in" match what's really on the page; a vague description gives Jev nothing to select from.
